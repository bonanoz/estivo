# Чек-лист переезда estivo63.ru с Tilda на Django

**Основа:** [MARKETING_AUDIT.md](../../MARKETING_AUDIT.md) (аудит от 20.10.2026), карта адресов [redirect_map.csv](redirect_map.csv), данные обхода [findings/09-crawl.tsv](findings/09-crawl.tsv).
**Принцип:** переносим **внешний вид** оригинала (стиль, фото, подачу), но **не переносим** найденные аудитом функциональные ошибки, мусорные данные и противоречивые тексты.

**Чего нет на момент составления:** данных Яндекс Метрики, Директа, VK Рекламы, Вебмастера, CRM и журнала звонков. Поэтому при переезде:
- ничего не решаем «по цифрам»;
- закладываем измерения (раздел 6), чтобы цифры появились после запуска;
- все приоритеты взяты из аудита: это гипотезы, проверенные на поведении сайта, а не на данных о продажах.

Обозначения: `[ ]` — не сделано; **R01–R28** — ID проблем из реестра аудита (раздел 10).

## 4. Импорт данных с Tilda

- [ ] **Источник** — экспорт каталога Tilda (CSV из «Товары» в Tilda Store) или API магазина. Тексты и цены сверять с [redirect_map.csv](redirect_map.csv) и `findings/09-crawl.tsv`.
- [ ] **Не импортировать:**
  - 7 демо-товаров и заглушку (`410` в карте);
  - «Copy:»-позиции — объединить с оригиналом;
  - 11 цветов-«товаров» — они становятся `ColorOption`;
  - юбки для ёлки — по решению владельца.
- [ ] **Дубли:** 41 строка с пометкой «то же название» — сверять **состав и цену** вручную. На Tilda одинаковое название бывает у разных комплектов (в распродаже «32», «6», «58»). Один товар — одна запись. Акция — через `old_price`, а не копией карточки.
- [ ] **Цены без «Цены по запросу» с нулём.** Нет цены — товар с явной пометкой «по запросу» и кнопкой «Узнать цену», в корзину по 0 ₽ не попадает (R08).
- [ ] **Сохранить Tilda-идентификатор** (число из `/tproduct/<id>-…`) у каждого импортированного товара. Это ключ для редиректов, чтобы не зависеть от будущего переименования.
- [ ] **Slug — через `shop.utils.ru_slugify`** (ASCII). Колонка `new_path` в карте — предложение по текущим названиям; после переименования комплектов пересчитать.
- [ ] **Импорт повторяемый и идемпотентный** (management-команда в духе `seed_demo`), с отчётом: сколько создано, пропущено, сколько дублей отправлено на ручную проверку.
