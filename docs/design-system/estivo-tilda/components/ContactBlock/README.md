# ContactBlock
Label/value pairs for phone, messengers, e-mail, address and hours: a 14px `muted` label over a 16px `ink` value.

- Provide: phone, messengers, e-mail, address, opening hours.
- One phone, one address, one legal entity across the site, /promo, VK, Telegram and Yandex (audit R05). The phone is the one value in `brand`; the header repeats it in `brand`.
- Messengers in this order: Telegram — a direct chat with the manager, not the channel; MAX; WhatsApp last, as a fallback (audit R18). State the reply time once the owner has confirmed it.
- Hours go one per line («Пн-Пт: 10:00-19:00»); the appointment note uses `contact-accent`, uppercase, in `brand`.
