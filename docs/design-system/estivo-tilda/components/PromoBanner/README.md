# PromoBanner
The full-width terracotta sale strip: one big uppercase Gilroy line and one dark button.

- Provide: a short offer (3 words max) and the button label and link to /salerotang or /saleroup.
- Placement: after the product screens, never the first block of the home page (audit R13). The home page opens with product, promise and proof.
- Sale numbers must be real: the old price is the catalogue price and the percentage adds up (audit R12). Prefer «Остатки со скидкой» over a headline percentage.
- `accent` ground, `banner` style in `on-dark` (3.1:1, passes at 40px+); the line scales from 100px down to 40px on phones. The button is `es-btn--dark` with an accent border and an uppercase label.
- One per page. Never set body-size text on `accent`.
