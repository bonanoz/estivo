# FactStrip
One hairline-ruled row of short facts under a product price and in the request panel: срок · доставка · гарантия · рассрочка · оплата (audit R06, E3, E6).

- Provide: 3–5 items in a `ul.es-facts`, each `li` holding a `b` label (`muted`) and the value (`ink`).
- Values come from the contract and must match /dostavka and /vozvrat. Until the owner confirms one, drafts show «[уточнить]» and production leaves the item out.
- The guarantee item links to the terms page. Keep values short; details live on the linked page.
- Wraps on phones; never scrolls sideways.
