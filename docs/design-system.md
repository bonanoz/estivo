# ESTIVO — дизайн-система

**Источник стиля:** `docs/design-system/estivo-tilda/` (`README.md`, `tokens.css`/`tokens.json`, `components/`), снято с
estivo63.ru и исправлено по `MARKETING_AUDIT.md`. Решение владельца от 22.10.2026: эта папка заменила прежние
`DESIGN.md`, `UX.md` и старую версию этого документа. Как токены и классы `es-*` легли на проект — в
`docs/design-system/estivo-tilda/MAPPING.md` (там же пробелы П1–П8).

**Источник значений в коде:** блок `@theme` в `internetshop/frontend/src/styles/main.css`. Если этот документ и CSS
расходятся, прав CSS, документ поправить. Если CSS и `estivo-tilda` расходятся, права `estivo-tilda`, кроме
отступлений, записанных в `MAPPING.md`. Саму папку `estivo-tilda/` (кроме `MAPPING.md`) без разрешения владельца не
менять.

**ОБЯЗАТЕЛЬНО** — правило без исключений. **СЛЕДУЕТ** — рекомендация, отступать можно с обоснованием.

## 1. Контекст

**Замысел:** тихие, светлые, «журнальные» страницы: почти белый фон, тёмно-коричневый текст, крупные заголовки
антиквой в верхнем регистре, один ржавый цвет для мелких сигналов и одна терракота для кнопки заявки и распродажи.

- **Продукт:** публичная витрина с лидогенерацией. Корзина собирает заявку, онлайн-оплаты нет. Не дашборд.
- **Аудитория:** частные покупатели, дизайнеры, B2B. Много мобильного трафика.
- **Стек:** Django-шаблоны + Tailwind CSS v4 (`@theme`) + htmx + Alpine.js + TypeScript, сборка Vite
  (`internetshop/frontend/` → `shop/static/dist/`). Общие компоненты — `@layer components` в `main.css`, страничные —
  `styles/{catalog,product,cart,pages}.css`. `components/bundle.css` из `estivo-tilda` **не подключается**: классы
  `es-*` переписаны в классы проекта (`.btn`, `.form-input`…), чтобы не держать две системы.

**Контраст (WCAG 2.x):** `ink`/`bg` 16,7 · `ink-soft`/`bg` 10,8 · `muted`/`bg` 5,1, на `surface-alt` 4,7 · `brand`/`bg`
5,85 · белый на `graphite` 12,6 · `on-accent` (ink) на `accent` 5,4 · белый на `accent` 3,1 (только 40px+) ·
`border-input`/`surface` **1,6** — ниже 3:1 по WCAG 1.4.11. Это осознанное отступление (П1): у каждого поля ОБЯЗАТЕЛЬНО
видимая подпись, фокус — `graphite`.

- ОБЯЗАТЕЛЬНО: в компонентах только `var(--color-*)`; сырые hex/rgb — только в `@theme`.
- ОБЯЗАТЕЛЬНО: `accent` — только кнопка заявки («Перейти к заявке» / «Получить расчёт», `.btn-primary`) и полоса
  распродажи. Исключение владельца: одна главная CTA в hero главной. Полоса распродажи — одна на страницу и не на первом экране (R13).
- ОБЯЗАТЕЛЬНО: `brand` не используется как фон крупных блоков.

  `--weight-body-regular` (300) / `--weight-body-bold` (800); 400–700 — где их задаёт estivo-tilda (на живом

- ОБЯЗАТЕЛЬНО: ничего мельче **14px** (`0.875rem`), включая бейджи, счётчик, подписи; `text-xs` запрещён (R22).
- ОБЯЗАТЕЛЬНО: заголовки хранятся в шаблонах в обычном регистре, верхний регистр — CSS.
- СЛЕДУЕТ: Light 300 на 14px тонкий — ставить на `bg`/`surface` цветом `ink`, не `muted` на `surface-alt`.
- Файлы `Gilroy-{Light,Regular,Medium,SemiBold,Bold,ExtraBold}.woff2` лежат в `shop/static/fonts/gilroy/`; без них — fallback
  `"Helvetica Neue", Arial, sans-serif`.

### 2.3 Сетка и отступы

- Контейнер `--container: 1160px` из пяти колонок `--module: 224px` с `--gutter: 10px`; блоки шириной 1, 2 или 3
  модуля (224 / 458 / 692px). `--container-narrow: 692px` — текстовые колонки. Ниже 768px — одна колонка, поля 16px.
- Отступы — проектная шкала `--space-1…8` (4, 8, 16, 24, 40, 64, 96, 128px): в `estivo-tilda` шкалы нет (П2).
  Секции разделяет воздух, а не линии и цветные полосы.
- Брейкпоинты Tailwind по умолчанию: `md` 768 (одна колонка ниже), `lg` 1024 (горизонтальное меню от него).
- ОБЯЗАТЕЛЬНО: нет горизонтальной прокрутки на 390px и 1440px (`scrollWidth <= innerWidth`).

### 2.4 Форма, границы, глубина

- `--radius-none` — фото, карточки, плитки (квадратные). `--radius-md` 5px — кнопки, поля, пилюли, бейджи.
  `--radius-sm` 4px — промо-кнопки, `.alert`. `--radius-pill` 30px — только кнопка cookie (эпик g). Круг — `.icon-btn`.
- Обведённые карточки — 1px `ink`; поля — 1px `border-input`.
- ОБЯЗАТЕЛЬНО: без теней (`box-shadow`, `shadow-*`) и градиентов.
- Слои — только `--z-dropdown` 10 · `--z-sticky` 20 · `--z-overlay` 40 · `--z-modal` 100 · `--z-toast` 1000 (П2).

### 2.5 Движение и состояния

- Hover кнопок, ссылок, карточек: `opacity: 0.85` за `var(--dur-fast) var(--ease)` (200ms ease-in-out). Другой системы
  движения нет.
- ОБЯЗАТЕЛЬНО: без `transform` на `:hover`/`:active` (подъём карточки, `scale` кнопки, zoom фото). Исключение —
  спиннер загрузки.
- ОБЯЗАТЕЛЬНО: фокус — `outline: 2px solid var(--color-brand); outline-offset: 2px` (глобальный `:focus-visible`).
- ОБЯЗАТЕЛЬНО: `prefers-reduced-motion: reduce` гасит анимации; JS-анимации проверяют `matchMedia` сами.

## 4. Доступность: критерии приёмки

Цель — WCAG 2.2 AA, с отступлением П1 (граница поля).

1. Текст до 24px — контраст ≥ 4.5:1; не мельче 14px нигде.
2. Фокус виден на каждом элементе (2px `brand`), не перекрыт липкой шапкой (`scroll-padding-top`).
3. Интерактивные элементы ≥ 44×44 (`--tap-min`).
4. Путь «товар → цвет → в корзину → заявка → отправка» проходится с клавиатуры.
5. У каждого поля видимая подпись; ошибки связаны через `aria-describedby`, фокус уходит в первое ошибочное поле.
6. `<html lang="ru">`, один `h1`, уровни без пропусков; у фото товара `alt` с названием, у декоративных — `alt=""`.
7. Нет горизонтальной прокрутки на 390 и 1440.

## 5. Тексты и тон

Полные правила — `estivo-tilda/README.md`, «Content fundamentals»; ниже главное.

- На «вы» (строчная), от мастерской — «мы». Спокойно и по фактам, без превосходных степеней: никаких
  «Rolls-Royce среди мебели», «Эверест мастерства» (аудит §14).
- Над каждым заголовком секции — eyebrow 1–3 слова 14px `brand` («Преимущества компании», «Отзывы», «FAQ»).
- Сайт принимает **заявки**, не платежи: «заявка», «расчёт», никогда «заказ» (кроме срока «под заказ»), «купить»,
  «оплатить» (R07). Кнопки — глагол в обычном регистре: «Получить расчёт», «Перейти к заявке», «Узнать цену»,
  «Подобрать комплект».
- Обещания — одной формулировкой из договора: гарантия **3 года**; в наличии — **отгрузка в течение 3 дней**, под
  заказ — **изготовление от 4 недель**; **договор, 50% предоплата, 50% после фото- и видеоотчёта**; каркас — «металл»;
  материал — «искусственный ротанг (ПЭ), ручное плетение»; −50…+50 °C — только у ротанга. Неизвестное — «[уточнить: …]»,
  а не число со старой страницы (SPEC `tilda-migration`, «Решения владельца»).
- Телефон один: +7 927 268-94-04 (`tel:+79272689404`). Продавец — ООО «Эстиво».
- У каждого предложения — цена, состав и дата окончания; после даты оно скрывается (R17, R26).
- Числа с неразрывным пробелом в разрядах и перед `₽` (`42&nbsp;000&nbsp;₽`). Без эмодзи.

## 6. Антипаттерны

- Сырые hex/rgb и одноразовые отступы вне токенов.
- Gilroy вне 300–800; текст мельче 14px.
- `accent` где-либо, кроме кнопки заявки и полосы распродажи; `brand` как фон блока.
- Тени, градиенты, скругления у фото и карточек, `transform` на hover/active.
- Тёмные секции и тёмный футер.
- `outline: none` без замены; плейсхолдер вместо подписи; `div` с кликом вместо `button`/`a`.
- Произвольный `z-index` вне `--z-*`.
- Запрещённые формулировки из §5 и SPEC «НЕ переносится».
