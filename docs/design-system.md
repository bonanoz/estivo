# ESTIVO — дизайн-система

Источник правды для значений: блок `@theme` в `internetshop/frontend/src/styles/main.css` (токены Tailwind v4). Этот документ описывает, как ими
пользоваться. Если документ и CSS расходятся, прав CSS, а документ нужно поправить.

Условные обозначения: **ОБЯЗАТЕЛЬНО** — правило без исключений (must). **СЛЕДУЕТ** — рекомендация, отступать
можно с обоснованием (should). Пометка 🆕 означает токен, который **предложен, но ещё не добавлен** в `@theme`.

---

## 1. Контекст и цели

**Замысел одной фразой:** тихая премиальная витрина плетёной мебели ручной работы — тёплый светлый фон,
крупная антиквенная типографика, фото как главный герой, терракота только как акцент.

- **Продукт:** публичный сайт-витрина (лидогенерация, без онлайн-оплаты). Корзина, заявка, формы для B2B и
  дизайнеров. Это **не** дашборд и не закрытый интерфейс.
- **Аудитория:** частные покупатели, дизайнеры интерьеров, B2B (отели, рестораны). Много мобильного трафика.
- **Стек:** Django-шаблоны + Tailwind CSS v4 (токены в `@theme`) + htmx + Alpine.js + TypeScript, сборка Vite
  (`internetshop/frontend/`, результат в `shop/static/dist/`). Общие компоненты (`.btn`, `.pill`, `.form-input`,
  `.alert` и др.) лежат в `frontend/src/styles/main.css` в `@layer components`, страничные — в соседних файлах
  `styles/{catalog,product,cart,pages}.css`. Без React/Next.js; старые рукописные CSS/JS удалены.
- **Цель документа:** чтобы любая новая страница или компонент собирались из существующих токенов и классов,
  не плодили исключений и проходили WCAG 2.2 AA.

- ОБЯЗАТЕЛЬНО: у body-шрифта только две насыщенности — `--weight-body-regular` (300) и `--weight-body-bold` (800).
  Gilroy бесплатен лишь в Light и ExtraBold. Значения 400/500/600/700 для `--font-body` запрещены.
- ОБЯЗАТЕЛЬНО: заголовки h1–h4 — `--font-display`, межстрочный `1.08`, `text-wrap: balance` (уже в `base.css`).
- ОБЯЗАТЕЛЬНО: основной текст не мельче `1rem`, вспомогательный (подписи, крошки) — не мельче `0.8rem`.
- СЛЕДУЕТ: Light 300 на мелком кегле читается плохо — подписи `0.8–0.85rem` ставить цветом `ink-soft` или
  темнее, а не `ink-muted`.
- СЛЕДУЕТ: длина строки в текстовых блоках — не больше ~70 символов (`--container-narrow: 820px`).

### 2.3 Отступы, сетка, брейкпоинты

- Шкала: `--space-1` 4 · `--space-2` 8 · `--space-3` 16 · `--space-4` 24 · `--space-5` 40 · `--space-6` 64 ·
  `--space-7` 96 · `--space-8` 128 (px).
- ОБЯЗАТЕЛЬНО: внешние отступы и `gap` — только токены `--space-*`. Внутренние паддинги контролов
  (`14px 30px` у кнопки, `14px 16px` у поля) — допустимое исключение, но одинаковое для всех контролов одного размера.
- СЛЕДУЕТ: вертикальный ритм секций — `--space-7` на десктопе, `--space-6` на мобильном.
- Контейнеры: `--container: 1240px`, `--container-narrow: 820px`.
- Брейкпоинты: mobile `< 640px`, tablet `640–960px`, desktop `> 960px`.
- ОБЯЗАТЕЛЬНО: на ширине 320px нет горизонтального скролла страницы.

### 2.4 Скругления, тени, слои

- Скругления: `--radius-sm` 6px (кнопки, поля, бейджи), `--radius-md` 12px (карточки), `--radius-lg` 20px
  (крупные панели, `.lead-form`), `999px` — только пилюли.
- Тени: `--shadow-sm` — спокойное состояние панелей; `--shadow-md` — hover карточки, поповеры. Однослойные
  жёсткие тени запрещены.
- z-index: только `--z-dropdown` 10 · `--z-sticky` 20 · `--z-overlay` 40 · `--z-modal` 100 · `--z-toast` 1000.
  ОБЯЗАТЕЛЬНО: никаких произвольных `z-index: 9999`.

### 2.5 Движение

Кривая одна: `--ease: cubic-bezier(0.22, 0.61, 0.36, 1)`. Длительности сейчас заданы в CSS числами; СЛЕДУЕТ
вынести их в токены:

| 🆕 Токен | Значение | Где сейчас |
|---|---|---|
| `--dur-press` | 120ms | `.btn:active` scale |
| `--dur-fast` | 200ms | цвет/граница полей и пилюль, hover кнопок (сейчас 0.2–0.25s) |
| `--dur-base` | 300ms | hover карточки, аккордеон (0.3–0.35s) |
| `--dur-slow` | 600ms | зум фото, scroll-reveal (0.6–0.7s) |

- ОБЯЗАТЕЛЬНО: `prefers-reduced-motion: reduce` гасит перемещение и масштаб (глобальное правило в `base.css`).
  JS-анимации (будущие GSAP/Lenis) ОБЯЗАНЫ проверять `matchMedia('(prefers-reduced-motion: reduce)')` сами —
  CSS-правило их не остановит.
- ОБЯЗАТЕЛЬНО: hover-эффекты со сдвигом (`translateY`, `scale`) только внутри `@media (hover: hover) and (pointer: fine)`,
  чтобы на тач-устройствах не «залипали».
- СЛЕДУЕТ: анимировать только `transform` и `opacity`. `max-height` у аккордеона — допустимое исключение.

## 3. Компоненты

Компоненты определены в `frontend/src/styles/main.css` (`@layer components`) и страничных CSS рядом. Лейблы-«eyebrow»
над заголовками **удалены** (правило design QA: никаких мелких трекинговых надписей над h1/h2); вместо них — сам
заголовок и lead-абзац.

Обязательные состояния для каждого интерактивного компонента: **default, hover, focus-visible, active,
disabled, loading, error** (те, что применимы). В таблицах ниже ⚠️ — состояние, которого в CSS сейчас нет.

### 3.1 Кнопка `.btn`

- **Анатомия:** контейнер (`inline-flex`, `gap: --space-2`) → опциональная иконка → подпись.
- **Варианты:** `.btn-primary` (одна главная CTA на экран), `.btn-outline` (вторичное действие), `.btn-light`
  (на тёмном или фото). Модификаторы: `.btn-lg`, `.btn-block`.
- **Типографика:** `--font-body`, `--weight-body-bold`, `0.98rem` (`.btn-lg` — `1.05rem`), `line-height: 1`.

| Состояние | Сейчас | Требование |
|---|---|---|
| default primary | белый на `accent` — 3.13 ❌ | ОБЯЗАТЕЛЬНО фон 🆕 `--color-accent-text` (5.27) или `--color-accent-dark` (4.69) |
| hover | `accent-dark`, `translateY(-2px)` только для fine pointer | оставить |
| focus-visible | глобальная обводка `accent` — 2.95 ❌ | ОБЯЗАТЕЛЬНО ≥3:1 к фону — см. §4 |
| active | `scale(.97)` | оставить |
| disabled | ⚠️ нет | ОБЯЗАТЕЛЬНО `[disabled], [aria-disabled="true"]`: `opacity:.5`, `cursor:not-allowed`, без hover и active |
| loading | ⚠️ нет | ОБЯЗАТЕЛЬНО `aria-busy="true"` + `disabled`, подпись остаётся (или «Отправляем…»), ширина не прыгает |

- **Клавиатура:** `<button>` для действий, `<a>` для навигации. Enter/Space срабатывают нативно; `div` с `onclick` запрещён.
- **Тач:** зона нажатия не меньше 44×44px (текущий паддинг даёт ~46px по высоте ✅).
- **Длинный текст:** подпись в одну строку на десктопе; на mobile кнопки в формах — `.btn-block`, текст
  переносится, а не обрезается.

### 3.2 Карточка товара `.product-card`

- **Анатомия:** `__media` (4:3, `object-fit: cover`, подложка `surface-alt`) → `.badge` (опц.) → `__body`:
  `__meta` (материал, uppercase) → `__title` → `__desc` → `__foot` (`__old` + `__price` + действие).
- **Состояния:** hover (только fine pointer) — `--shadow-md`, `translateY(-4px)`, зум фото 1.05.
  focus-visible — ОБЯЗАТЕЛЬНО видимая обводка на ссылке карточки; если ссылка растянута на всю карточку,
  СЛЕДУЕТ показывать обводку на карточке целиком через `:focus-within`.
- **Длинный контент:** `__title` — до 2 строк, `__desc` — до 3 строк через `-webkit-line-clamp`; полный текст
  остаётся в DOM. Цена ОБЯЗАТЕЛЬНО не переносится (`white-space: nowrap`).
- **Пустые состояния:** нет фото → плейсхолдер `img/placeholders/*.svg` (уже в шаблонах); нет цены → «Цена по запросу»,
  а не «0 ₽»; пустой каталог → текст + кнопка «Смотреть все коллекции», а не пустая сетка.
- **Сетка:** 1 колонка < 640px, 2 — tablet, 3 — desktop; `gap: --space-4`.

### 3.3 Поля формы `.form-field` / `.form-input`

- **Анатомия:** `label` (`0.85rem`, bold, `ink-soft`) → `.form-input` → `.form-errors` (опц.) → `.form-note` (опц.).
- ОБЯЗАТЕЛЬНО: у каждого поля видимый `<label for>`; плейсхолдер не заменяет label.
- ОБЯЗАТЕЛЬНО: граница поля — 🆕 `--color-line-strong` (сейчас `line` — 1.35 ❌).

| Состояние | Требование |
|---|---|
| focus / focus-visible | граница `accent-text` + кольцо `0 0 0 3px var(--color-accent-soft)` |
| error | ⚠️ сейчас красный только текст. ОБЯЗАТЕЛЬНО: граница `--color-error`, `aria-invalid="true"`, текст ошибки связан через `aria-describedby`, цвет текста — 🆕 `--color-error` |
| disabled | ⚠️ нет. `background: surface-alt`, `color: ink-muted`, `cursor: not-allowed` |

- **Телефон:** маска из `forms.js` не мешает вставке из буфера и автозаполнению (`autocomplete="tel"`).
- ОБЯЗАТЕЛЬНО: `font-size` поля не меньше `1rem`, иначе iOS зумит страницу при фокусе.
- **Ошибка отправки:** сообщение над формой, фокус переводится на первое поле с ошибкой.

### 3.4 Форма заявки `.lead-form`

- Панель: `surface`, `--radius-lg`, паддинг `--space-5` (СЛЕДУЕТ `--space-4` на mobile), `--shadow-sm`.
- Кнопка отправки — `.btn-primary .btn-block`, на время отправки переходит в состояние loading (§3.1).
- После успеха — редирект на страницу «Спасибо» (так уже работает), а не тихое очищение формы.
- Под кнопкой — `.form-note` про согласие на обработку персональных данных со ссылкой на политику.

### 3.5 Сообщение `.alert`

- Сейчас: `accent-dark` на `accent-soft` — 4.32 ❌. ОБЯЗАТЕЛЬНО: текст 🆕 `--color-accent-text`.
- СЛЕДУЕТ: варианты `.alert--success` / `.alert--error` (с `--color-error`) вместо одного общего вида.
- ОБЯЗАТЕЛЬНО: сообщения о результате действия объявляются скринридеру (`role="status"`, для ошибок — `role="alert"`).

### 3.6 Аккордеон FAQ `.faq-item` (нативный `<details>`)

- `.accordion-trigger` ОБЯЗАТЕЛЬНО `<button>` с `aria-expanded` и `aria-controls`; панель — с `id`.
- Клавиатура: Tab переходит между заголовками, Enter/Space раскрывает. Несколько панелей могут быть открыты одновременно.
- Иконка «+» поворачивается на 45°, её цвет — `accent` (иконка не текст, достаточно 3:1 на `bg`: 2.95 ❌ →
  СЛЕДУЕТ `accent-text`).
- Длинный ответ: `max-height` берётся из `scrollHeight` в JS, а не из фиксированного числа.

### 3.7 Пилюли-фильтры `.pill`

- Активная: `ink`-заливка — ✅. Hover: сейчас текст `accent` — 3.13 ❌ → ОБЯЗАТЕЛЬНО `accent-text`.
- ОБЯЗАТЕЛЬНО: активная пилюля помечена `aria-current="page"` (если это ссылка) или `aria-pressed="true"`
  (если кнопка-переключатель).
- Переполнение: пилюли переносятся (`flex-wrap`, уже так). СЛЕДУЕТ на mobile горизонтальный скролл-ряд
  со `scroll-snap`, если фильтров больше 6.

### 3.8 Свотч цвета `.swatch`

- ОБЯЗАТЕЛЬНО: свотч — радио-кнопка (`<input type="radio">` + `label`), группа — `fieldset` с `legend`
  («Плетение», «Подушки», «Каркас»).
- ОБЯЗАТЕЛЬНО: название цвета доступно как текст (`aria-label` или видимая подпись), цвет не единственный носитель информации.
- Выбранный свотч — кольцо `ink` 2px с отступом, контраст кольца к фону ≥3:1.
- Клавиатура: стрелки переключают цвет внутри группы (нативное поведение радио).

### 3.9 Хлебные крошки и пагинация

- Крошки: `nav aria-label="Хлебные крошки"`, текущая страница — текст с `aria-current="page"`, без ссылки.
  Hover-цвет — `accent-text`.
- Пагинация: `nav aria-label="Страницы"`, текущая — `aria-current="page"`; зона клика ≥44px на тач.

## 4. Доступность: критерии приёмки

Цель — WCAG 2.2 AA. Каждый пункт проверяется в браузере или автоматическим тестом.

1. **Контраст текста.** Любой текст до 24px (18.66px жирным) имеет контраст ≥4.5:1 к фону. Проверка: axe /
   Lighthouse не находят нарушений `color-contrast` на главной, в каталоге, на странице товара, в корзине и в оформлении.
2. **Контраст не-текста.** Границы контролов, обводка фокуса, иконки-носители смысла — ≥3:1. Проверка: таблица §2.1.
3. **Видимый фокус.** На каждом интерактивном элементе при Tab видна обводка шириной ≥2px и контрастом ≥3:1
   к соседним цветам. СЛЕДУЕТ сменить глобальный `:focus-visible` на `outline: 2px solid var(--color-accent-text)`
   (на тёмных секциях — `--color-dark-ink`). Проверка: пройти Tab-ом всю страницу товара.
4. **Фокус не перекрыт** (2.4.11). Липкая шапка не закрывает элемент в фокусе: `scroll-padding-top` ≥ высоты шапки.
5. **Клавиатура.** Весь путь «товар → выбор цвета → в корзину → оформление → отправка» проходится без мыши.
   Проверка: ручной прогон, мышь не трогаем.
6. **Размер цели** (2.5.8). Интерактивные элементы ≥24×24px, основные действия на тач — ≥44×44px.
7. **Формы.** У каждого поля есть label; ошибки связаны через `aria-describedby`; при ошибке фокус уходит в первое
   ошибочное поле. Проверка: отправить пустую форму на `/contacts/`.
8. **Движение.** С включённым «уменьшить движение» на странице нет перемещений и параллакса (включая JS-анимации).
   Проверка: DevTools → Rendering → `prefers-reduced-motion: reduce`.
9. **Изображения.** У фото товара `alt` с названием и материалом; декоративные — `alt=""`.
10. **Язык и структура.** `<html lang="ru">`, один `h1` на страницу, уровни заголовков без пропусков.

## 6. Антипаттерны (запрещено)

- Сырые hex/rgb и «одноразовые» отступы в компонентах вместо токенов.
- `font-weight` 400/500/600/700 для Gilroy (`--font-body`).
- Терракота (`--color-accent`) для мелкого текста и тонких линий на светлом фоне.
- `outline: none` без замены видимым фокус-индикатором.
- `div`/`span` с обработчиком клика вместо `button`/`a`.
- Плейсхолдер вместо label.
- Hover-сдвиги без `@media (hover: hover) and (pointer: fine)`.
- JS-анимации без проверки `prefers-reduced-motion`.
- Произвольный `z-index` вне шкалы `--z-*`.
- Подключение библиотек (GSAP, Swiper) глобально в `base.html`, если они нужны на одной странице.
- Тексты «Подробнее», «Нажмите здесь», «Ошибка» без пояснения.

## 7. Миграция: выполнена

Миграция с рукописного CSS (`variables / base / layout / components / pages.css`) и vanilla JS (`main / forms / cart /
product-gallery / product-3d.js`) на Tailwind v4 + htmx + Alpine + TS завершена; старые файлы и подключение
`@layer legacy` удалены. Поведение перенесено в бандл: маска телефона и защита от двойной отправки — `src/forms`,
блокировка прокрутки для оверлеев — `src/lib/scroll-lock.ts`, мобильное меню — Alpine в `_header.html`,
FAQ — нативный `<details>`. Reveal-анимации при прокрутке убраны (контент никогда не скрывается).
`static/js/vendor/model-viewer.min.js` остаётся: он грузится только на PDP с 3D-моделью.

Что делать при добавлении UI: брать токены из `@theme`, компонент — в `@layer components`, поведение — в
`frontend/src/<feature>/index.ts` (подхватывается автоматически), затем `npm run build` и `collectstatic`.
