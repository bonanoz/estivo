# Коллекции

Серии мебели (Милан, Бари, Асти и следующие), разложенные по зонам: список коллекций на /kollekcii/ и страница коллекции с разделами «Обеденная группа», «Лаунж-зона» и другими зонами из справочника. Один товар может входить в несколько коллекций; зона — свойство товара. Ведутся в админке (см. admin.md). Введено фичей collections (docs/specs/collections/SPEC.md).

## Требование: список коллекций
Система ДОЛЖНА по /kollekcii/ показывать крошки «Главная / Коллекции», заголовок «Коллекции» и коллекции в порядке поля «порядок»: обложка (или заглушка), название, ссылка на страницу коллекции. Выводятся только коллекции хотя бы с одним показываемым товаром. Если таких нет — «Коллекции скоро появятся. А пока посмотрите весь каталог.» со ссылкой на /catalog/. Пункт «Коллекции» стоит в меню сразу после «Каталог» (см. site-shell.md).

- Сценарий «список»: КОГДА есть «Милан» с 3 товарами и «Бари» с 1 ТОГДА видны обе со ссылками на /kollekcii/milan/ и /kollekcii/bari/
- Сценарий «пустая коллекция»: КОГДА у коллекции нет товаров ТОГДА её на странице нет
- Сценарий «все сняты»: КОГДА все товары коллекции сняты с показа ТОГДА её на странице нет
- Сценарий «ничего нет»: КОГДА ни у одной коллекции нет показываемых товаров ТОГДА видно «Коллекции скоро появятся» и ссылка на /catalog/

## Требование: страница коллекции
Система ДОЛЖНА по /kollekcii/<slug>/ показывать крошки «Главная / Коллекции / <название>», заголовок «Коллекция «<название>»», описание (если есть), ссылки-якоря на зоны (при двух и более разделах) и разделы по зонам в порядке зон: заголовок зоны и карточки её показываемых товаров, как в каталоге. Товары без зоны идут последним разделом «Ещё в коллекции». Зоны без показываемых товаров не выводятся. Внутри зоны товары идут по порядку категории, затем по цене и названию.

- Сценарий «две зоны»: КОГДА в «Милане» 2 товара обеденной группы и 3 лаунж ТОГДА видны «Обеденная группа» (2 карточки), затем «Лаунж-зона» (3 карточки)
- Сценарий «якорь»: КОГДА пользователь нажимает «Лаунж-зона» в ссылках наверху ТОГДА страница переходит к разделу, заголовок не перекрыт шапкой
- Сценарий «без зоны»: КОГДА у товара коллекции нет зоны ТОГДА он в «Ещё в коллекции» после всех зон
- Сценарий «пустая зона»: КОГДА в зоне нет товаров коллекции ТОГДА ни раздела, ни якоря нет
- Сценарий «общий стол»: КОГДА стол входит в «Милан» и «Бари» ТОГДА его карточка есть на обеих страницах
- Сценарий «снятый товар»: КОГДА товар коллекции снят с показа ТОГДА его карточки нет
- Сценарий «нет такой»: КОГДА пользователь открывает /kollekcii/net-takoy/ ТОГДА 404
- Сценарий «пустая по ссылке»: КОГДА у коллекции нет показываемых товаров и пользователь открывает её адрес ТОГДА 404

## Требование: SEO коллекций
Система ДОЛЖНА давать странице коллекции title «Коллекция «<название>» — уличная мебель ESTIVO», description из первых 160 символов описания коллекции (при пустом — «Коллекция «<название>» от ESTIVO: обеденная группа и лаунж-зона из роупа ручной работы. Гарантия 3 года.»), canonical на основном домене и og:image из обложки, если она есть. /kollekcii/ и страницы коллекций с показываемыми товарами есть в sitemap (см. seo.md).

- Сценарий «title»: КОГДА открыта /kollekcii/milan/ ТОГДА title «Коллекция «Милан» — уличная мебель ESTIVO»
- Сценарий «пустое описание»: КОГДА у коллекции нет описания ТОГДА description по шаблону с её названием

## Требование: коллекции на странице товара
Система ДОЛЖНА у показываемого товара под названием выводить «Коллекция: <название>» или «Коллекции: <название>, <название>» со ссылками на страницы коллекций в порядке коллекций; у товара без коллекций и у снятого с показа строки нет.

- Сценарий «одна»: КОГДА товар входит в «Милан» ТОГДА под названием «Коллекция: Милан» со ссылкой на /kollekcii/milan/
- Сценарий «две»: КОГДА товар в «Милан» и «Бари» ТОГДА «Коллекции: Милан, Бари» с двумя ссылками
- Сценарий «нет»: КОГДА товар без коллекций или снят с показа ТОГДА строки нет
