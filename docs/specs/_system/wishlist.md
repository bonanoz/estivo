# Избранное

Сессионное избранное без регистрации: сердечко на карточках и странице товара, счётчик в шапке, страница /wishlist/.

## Требование: добавление и удаление
Система ДОЛЖНА по нажатию на сердечко карточки или страницы товара добавлять товар в избранное, а повторным нажатием убирать; с JS кнопка меняет состояние «нажата/не нажата» без перезагрузки, счётчик в шапке обновляется. Неизвестный товар даёт 404; снятый с показа товар нельзя добавить, но можно убрать, если он уже в избранном.

- Сценарий «добавить»: КОГДА пользователь на /catalog/ нажимает сердечко карточки ТОГДА сердечко помечено нажатым, у значка избранного «1»
- Сценарий «убрать»: КОГДА пользователь нажимает то же сердечко ещё раз ТОГДА пометка снята, счётчик скрыт
- Сценарий «состояние после перезагрузки»: КОГДА товар в избранном и пользователь открывает его страницу ТОГДА сердечко уже помечено
- Сценарий «неизвестный товар»: КОГДА клиент делает POST /wishlist/toggle/999999/ ТОГДА получает 404
- Сценарий «снятый товар»: КОГДА клиент делает POST /wishlist/toggle/<id снятого товара, которого нет в избранном>/ ТОГДА получает 404
- Сценарий «не тот метод»: КОГДА клиент делает GET /wishlist/toggle/<id>/ ТОГДА получает 405
- Сценарий «без JS»: КОГДА JS выключен и пользователь нажимает сердечко ТОГДА ничего не происходит

[?] Сердечко сделано кнопкой без формы и работает только через JS: без JS нажатие ничего не делает, хотя обработчик умеет вернуть на прежнюю страницу (views.py:521), а CLAUDE.md:164 обещает работу избранного без JS (_product_card.html:23-28, product_detail.html:85-90)

## Требование: страница избранного
Система ДОЛЖНА на /wishlist/ показывать карточки товаров из избранного в порядке добавления, только показываемые на сайте; при пустом избранном — «Здесь пока пусто», пояснение и «Перейти в каталог».

- Сценарий «два товара»: КОГДА пользователь добавил два товара и открыл /wishlist/ ТОГДА видит две карточки в порядке добавления
- Сценарий «пусто»: КОГДА пользователь без избранного открывает /wishlist/ ТОГДА видит «Здесь пока пусто» и ссылку на /catalog/
- Сценарий «товар сняли»: КОГДА товар из избранного сняли с показа ТОГДА его карточки на /wishlist/ нет

## Требование: счётчик избранного в шапке
Система ДОЛЖНА показывать у значка избранного число товаров в избранном и скрывать его при нуле.

- Сценарий «счётчик»: КОГДА в избранном 3 товара ТОГДА у значка «3»
- Сценарий «снятый товар»: КОГДА в избранном 2 товара и один сняли с показа ТОГДА на /wishlist/ одна карточка, а у значка «2»

[?] Счётчик считает все сохранённые id, включая снятые и удалённые товары, а страница их не показывает (wishlist.py:22-27 против wishlist.py:54); у корзины счётчик снятые товары пропускает (cart.py:136-138)
