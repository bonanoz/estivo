# Контентные страницы

Главная, «О нас», «Доставка и оплата», «Гарантия», «Вопросы и ответы», «Контакты», «Для бизнеса», «Дизайнерам» и политика конфиденциальности. Формы этих страниц описаны в leads.md, согласие на cookie — в analytics.md.

## Требование: главная страница
Система ДОЛЖНА на / показывать по порядку: первый экран с H1 «Плетёная мебель из ротанга и роупа», одной основной кнопкой «Подобрать комплект» (на /kontakty/) и ссылками «Каталог ротанга» и «Каталог роупа»; строку доказательств (гарантия, изготовление, 3 цеха и склад 650 м², доставка); «Популярные модели» — до 8 товаров для главной с ценой больше 0; «Кто мы»; материалы; «Почему ESTIVO»; «Как мы работаем»; три сегмента; до 6 опубликованных отзывов; блок «Получить консультацию».

- Сценарий «главная»: КОГДА пользователь открывает / ТОГДА видит один H1 и одну терракотовую кнопку «Подобрать комплект» на первом экране
- Сценарий «ссылки на каталоги»: КОГДА пользователь нажимает «Каталог ротанга» ТОГДА открывается /catalog/rotang/
- Сценарий «сегменты»: КОГДА пользователь нажимает «Условия для бизнеса» и «Обсудить проект» ТОГДА попадает на /b2b/ и /for-designers/
- Сценарий «товар по запросу»: КОГДА товар для главной имеет цену 0 ТОГДА в «Популярных моделях» его нет
- Сценарий «нет отзывов»: КОГДА опубликованных отзывов нет ТОГДА секции «Отзывы клиентов» нет
- Сценарий «нет товаров»: КОГДА ни один товар не отмечен для главной ТОГДА секции «Популярные модели» нет

## Требование: страницы о компании и условиях
Система ДОЛЖНА отдавать 200, один H1 и хлебные крошки на /o-nas/ (ручное плетение, материалы, 8 этапов создания), /dostavka-i-oplata/ (оформление, оплата по договору 50% + 50% после фото- и видеоотчёта, доставка ТК до двери, сроки: в наличии отгрузка в течение 3 дней, под заказ от 4 недель), /garantiya/ (гарантия 3 года, сертификаты, возврат по договору). Гарантия везде одна — 3 года.

- Сценарий «о нас»: КОГДА пользователь открывает /o-nas/ ТОГДА видит H1 про своё производство в Тольятти и «8 этапов создания мебели»
- Сценарий «доставка»: КОГДА пользователь открывает /dostavka-i-oplata/ ТОГДА видит «50% предоплата» и «Онлайн-оплаты на сайте нет»
- Сценарий «гарантия»: КОГДА пользователь открывает /garantiya/ ТОГДА видит H1 «Гарантия 3 года» и нигде нет «5 лет» или «24 месяца»
- Сценарий «запрещённые фразы»: КОГДА пользователь открывает любую контентную страницу ТОГДА нет «[уточнить», «натуральн», «Оформить заказ», «ИП Мелихова», «−70»

## Требование: вопросы и ответы
Система ДОЛЖНА на /faq/ показывать шесть частых вопросов раскрывающимися блоками (как сделать заявку, нагрузка до 120 кг, климат −50…+50°C для ротанга, каркас из металла, порошковая окраска, ткани и наполнитель) и блок «Обсудим вашу мебель?». Тот же список выводится под сеткой каталога.

- Сценарий «раскрытие»: КОГДА пользователь нажимает вопрос на /faq/ ТОГДА появляется ответ, повторное нажатие его скрывает
- Сценарий «без JS»: КОГДА JS выключен ТОГДА вопросы всё равно раскрываются

## Требование: страницы для бизнеса и дизайнеров
Система ДОЛЖНА на /b2b/ показывать H1 «Оснащение отелей, ресторанов и кафе», цифры (объёмы, сроки, гарантия, КП), условия для бизнеса и кнопку «Запросить коммерческое предложение», ведущую к форме на той же странице; на /for-designers/ — H1 «Мебель по вашему эскизу», возможности производства и кнопку «Обсудить дизайн-проект» к форме. Фото берутся из настроек сайта, без них — фото цеха.

- Сценарий «якорь B2B»: КОГДА пользователь на /b2b/ нажимает «Запросить коммерческое предложение» ТОГДА страница прокручивается к «Расскажите о вашем объекте»
- Сценарий «фото из админки»: КОГДА в настройках сайта загружено фото для B2B ТОГДА на /b2b/ показано оно, иначе фото мастера из цеха

## Требование: политика конфиденциальности
Система ДОЛЖНА на /privacy/ показывать политику оператора ООО «Эстиво» (ИНН 6321368220, ОГРН, юридический адрес), разделы 1–12 и раздел 13 «Cookie и Яндекс Метрика» с якорем #cookie (сессионные cookie корзины и избранного, Метрика 93915751, Вебвизор после согласия). Каждая форма сайта ссылается на /privacy/.

- Сценарий «политика»: КОГДА пользователь открывает /privacy/ ТОГДА видит «ООО «Эстиво»», «6321368220», «Метрик», «cookie»
- Сценарий «ссылка из форм»: КОГДА пользователь открывает /kontakty/, /b2b/ или /cart/checkout/ ТОГДА у формы есть ссылка «обработкой персональных данных» на /privacy/
- Сценарий «якорь»: КОГДА пользователь открывает /privacy/#cookie ТОГДА страница прокручена к разделу 13
