# Дизайн-система

Проверяемые правила внешнего вида из docs/design-system.md: шрифты, размеры, запреты, правило терракотовой кнопки, сетка, доступность, движение и тон текстов. Только то, что можно проверить в браузере (вычисленные стили, размеры) или тестом по исходникам.

## Требование: шрифты и размеры текста
Система ДОЛЖНА набирать заголовки антиквой Literata весом 400 без прописных, основной текст — Onest 400 размером 16/24, кнопки и подписи интерфейса — Onest 600, цены — 800; Onest используется только в весах 300–800. Нигде на сайте нет текста мельче 14px, включая бейджи, счётчики и подписи. Если файлы Onest не загрузились, текст идёт запасным шрифтом без поломки вёрстки.

- Сценарий «заголовки»: КОГДА проверяются вычисленные стили H1 и H2 на /, /catalog/, /product/<slug>/ ТОГДА семейство Literata, вес 400, text-transform не uppercase
- Сценарий «минимальный размер»: КОГДА скрипт обходит все видимые текстовые элементы /, /catalog/, /product/<slug>/, /cart/, /cart/checkout/ на 390 и 1440px ТОГДА ни у одного font-size меньше 14px
- Сценарий «запрещённые веса»: КОГДА тест проверяет исходники стилей и шаблонов ТОГДА у основного шрифта нет весов 100, 200, 900

## Требование: запреты оформления
Система ДОЛЖНА не использовать тени и градиенты, тёмные секции, линии-разделители и рамки у блоков (1px-граница только у полей, пилюль и переключателей), подписи капсом над заголовками; при наведении и нажатии элементы не сдвигаются и не масштабируются — наведение меняет только прозрачность до 0,85. Серая секция — не больше одной на страницу. Фото и карточки товаров без скруглений.

- Сценарий «тени»: КОГДА скрипт проверяет вычисленные стили всех элементов страницы /catalog/ ТОГДА box-shadow у всех none, в background-image нет gradient
- Сценарий «наведение»: КОГДА пользователь наводит курсор на карточку товара и на кнопку «В корзину» ТОГДА transform не меняется, меняется только прозрачность
- Сценарий «серые секции»: КОГДА проверяется любая публичная страница ТОГДА на ней не больше одной серой секции
- Сценарий «подписи над заголовками»: КОГДА проверяются /, /catalog/rotang/, /product/<slug>/ ТОГДА над H1 нет строки мелкого капса

## Требование: терракотовая кнопка только для заявки
Система ДОЛЖНА окрашивать акцентным цветом только кнопки, ведущие к заявке: «Подобрать комплект» на главной (одна), «Оформить заявку» на товаре, «Перейти к заявке», «Получить расчёт», «Оставить заявку», «Получить консультацию», кнопки B2B и «Дизайнерам», промо-карточка. В видимой группе действий — не больше одной такой. «В корзину», «Применить», «Отправить отзыв», «Узнать цену» у товара без цены — графитовые. Промо-полоса и подвал без акцентного цвета.

- Сценарий «товар»: КОГДА пользователь открывает /product/<slug>/ с ценой ТОГДА «Оформить заявку» терракотовая, «В корзину — N ₽» графитовая
- Сценарий «товар без цены»: КОГДА пользователь открывает товар с ценой 0 ТОГДА «Узнать цену» графитовая
- Сценарий «корзина»: КОГДА пользователь открывает /cart/ с товаром ТОГДА терракотовая кнопка одна — «Перейти к заявке», «Продолжить покупки» — текстовая ссылка
- Сценарий «главная»: КОГДА пользователь открывает / ТОГДА на первом экране одна терракотовая кнопка

## Требование: сетка и адаптивность
Система ДОЛЖНА держать содержимое в колонке до 1360px с полями страницы от 16 до 48px (одинаковыми у шапки, подвала, промо-полосы и страниц) и не давать горизонтальной прокрутки на ширине 360, 390 и 1440px. Поля ввода и крупные кнопки высотой 52px, интерактивные элементы не меньше 44×44px, у полей ввода шрифт не меньше 16px.

- Сценарий «без прокрутки вбок»: КОГДА скрипт открывает все публичные страницы, /cart/, /cart/checkout/ на 360, 390 и 1440px ТОГДА scrollWidth не больше innerWidth
- Сценарий «зоны нажатия»: КОГДА скрипт измеряет кнопки, ссылки меню, иконки шапки и переключатели цвета на 390px ТОГДА каждая зона не меньше 44×44
- Сценарий «ширина 1440»: КОГДА пользователь открывает /catalog/ на 1440px ТОГДА сетка товаров шириной 1344px с полями по 48px

## Требование: доступность
Система ДОЛЖНА показывать фокус клавиатуры рамкой 2px фирменного ржавого цвета с отступом 2px на каждом элементе и не прятать его под липкой шапкой; у каждого поля видимая подпись; у фото товара alt с названием, у декоративных — пустой; страница на русском, H1 один, уровни заголовков без пропусков. Путь «товар → цвет → в корзину → заявка → отправка» проходится с клавиатуры.

- Сценарий «фокус»: КОГДА пользователь проходит Tab по /product/<slug>/ ТОГДА у каждого элемента в фокусе видна рамка 2px
- Сценарий «клавиатура до заявки»: КОГДА пользователь только клавиатурой выбирает цвет, жмёт «Оформить заявку», заполняет форму и отправляет ТОГДА открывается /order/success/
- Сценарий «подписи полей»: КОГДА проверяются формы /kontakty/, /cart/checkout/, форма отзыва ТОГДА у каждого видимого поля есть связанная подпись
- Сценарий «уровни заголовков»: КОГДА проверяется /catalog/ ТОГДА после H1 идёт H2 (скрытый «Модели»), затем H3 карточек

## Требование: движение
Система ДОЛЖНА анимировать сдержанно и только эти четыре вида: появление блоков и карточек ниже первого экрана при прокрутке (прозрачность и сдвиг около 14px за 500 мс, карточки каскадом), плавный переход между страницами, подпрыгивание счётчиков корзины и избранного и сердечка при изменении, плавное раскрытие вопросов и аккордеонов. При настройке «уменьшить движение» и без JS всё видно сразу и ничего не движется.

- Сценарий «прокрутка»: КОГДА пользователь прокручивает / ТОГДА блоки ниже первого экрана проявляются, первый экран не мигает
- Сценарий «счётчик»: КОГДА пользователь добавляет товар в корзину ТОГДА счётчик в шапке коротко увеличивается и возвращается
- Сценарий «уменьшить движение»: КОГДА в системе включено «уменьшить движение» ТОГДА контент виден сразу, переходов между страницами и проявления нет
- Сценарий «без JS»: КОГДА JS выключен ТОГДА все блоки видны

## Требование: тексты и иконки
Система ДОЛЖНА писать на «вы», про заявку и расчёт, без слов «заказ» (кроме срока «под заказ»), «купить», «оплатить» в интерфейсе («купить» разрешено в title страниц категорий, решение владельца 02.11.2026, docs/design-system.md §5); обещания одной формулировкой: гарантия 3 года, отгрузка в течение 3 дней / изготовление от 4 недель, договор 50% + 50% после фото- и видеоотчёта, каркас из металла, −50…+50 °C только у ротанга; один телефон +7 927 268-94-04; без эмодзи на страницах. Иконки — линейные, толщина линии 1,5.

- Сценарий «слова»: КОГДА проверяются /, /catalog/, /product/<slug>/, /cart/, /cart/checkout/, /order/success/ ТОГДА нет «Оформить заказ», «Купить», «Оплатить»
- Сценарий «иконки»: КОГДА тест проверяет SVG в шаблонах ТОГДА толщина линии везде 1.5
