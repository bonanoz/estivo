### (c) Импорт товаров с Tilda

**Зависит от:** — (схема — после утверждения). **Заблокирован частично:** нужен CSV-экспорт каталога Tilda Store от владельца — [уточнить: файл]. Команда и тесты делаются на фикстуре; запуск на реальных данных — после получения файла. **R:** R08, R09, R10, R11, R12, R19. **ЧЛ:** 4.

- c1. Миграция: `Product.tilda_id`, nullable `temp_min_c/temp_max_c` (данные: у существующих товаров не-ротанга обнулить, у ротанга −50/+50).
- c2. `python manage.py import_tilda <csv> [--dry-run]` в духе `seed_demo`: идемпотентно по `tilda_id` (`update_or_create`); slug через `shop.utils.ru_slugify`; материал и категория — по разделу Tilda (как в `redirect_map.csv`: угловые диваны → «Диваны», хранение → без категории); `warranty_years=3`; температура −50/+50 только у ротанга; цена «по запросу»/пусто → `price=0`.
- c3. Не импортировать: 7 демо-товаров (`410` в карте), «Copy:»-позиции (сливаются с оригиналом по названию — оригинал получает фото/текст, если пусто), 11 цветов-как-товаров (→ `ColorOption` типа «Плетение», `get_or_create` по имени), юбки для ёлки ([уточнить] — пропуск с причиной).
- c4. Дубли: 41 строка «то же название» и расхождения цен из R12 (роуп 1–5, 17, «Кокон Комо Люкс 2х», «Милан» HPL) — **не создаются**, попадают в отчёт `import_report.csv` (вне git) для ручной проверки.
- c5. Отчёт в консоль: создано / обновлено / пропущено (по причинам) / на ручной проверке.
- c6. Тексты при импорте чистятся: убрать «Error get alias», «BUY NOW», «Copy:»; «натуральный» → нет (товар уходит в отчёт, текст не правится молча).

**Уточнения по реальному CSV (23.10.2026)** — `store-10482059-202610230738.csv`, 797 строк, разделитель `;`, UTF-8 с BOM, колонки `Tilda UID;Brand;SKU;Mark;Category;Title;Description;Text;Photo;Price;Quantity;Price Old;Editions;Modifications;External ID;Parent UID;Characteristics:Тип;Weight;Length;Width;Height`. 235 строк-товаров + 562 строки-варианта (`Parent UID` заполнен, `Editions` вида `Габариты:1500х800х700мм`).

Решения владельца:
- **Варианты** (20 товаров): один `Product` на родителя, `price` = минимальная цена его вариантов («от»); список уникальных вариантов «`<Editions>` — `<цена>` ₽» добавляется в конец `description`. Строки-варианты товарами не становятся.
- **Старая цена** (`Price Old` > `Price`, вся распродажа и строки вроде «№ 93»): покупатель видит **полную** цену — `price = Price Old`, `sale_price = Price`, `old_price = None`. Скидка «в запасе», включается в админке действием. Без `Price Old` или `Price Old <= Price` — `price = Price`, `sale_price = None`.
- **Фото**: флаг `--with-photos` — скачать URL из `Photo` (несколько через пробел/запятую: первое → `main_image`, остальные → `ProductImage`); только если у товара фото ещё нет; ошибка загрузки → предупреждение в отчёте, импорт не падает. Без флага фото не трогаются. В тестах сеть мокается.
- **Демо-товары seed_demo** не трогаются: импорт меняет только `Product` с `tilda_id`.
- Правка `MAX`-ссылки на номер 927 200-43-03 — решение владельца (исключение из правила одного телефона).

Правила разбора (допущения оркестратора):
- **Пропуск «демо»**: пустой `Category` (6 демо-товаров + «sale роуп» = 7 строк `410` в карте).
- **Цвета**: раздел «Цвета ротанга» → `ColorOption(finish_type=weave)`, `get_or_create` по имени, не товар.
- **Юбки**: «юбк» в названии (без учёта регистра) → пропуск, причина «юбка для ёлки — [уточнить]».
- **Copy:**: название без «Copy: »; если оригинал с таким названием есть в CSV — строка пропускается, оригинал получает её `Text`/фото, если у него пусто; если оригинала нет — импортируется под очищенным названием со своим `tilda_id`.
- **Дубли**: среди оставшихся родительских строк одинаковое название (`casefold`, пробелы схлопнуты) у ≥ 2 строк → **все** строки группы не создаются, идут в `import_report.csv` с причиной «то же название». Явный список ручной проверки R12: «Стол Милан с HPL 180х110 см (роуп)».
- **Материал**: если в названии ровно один маркер материала — по названию (решение оркестратора после ревью 23.10.2026: «Разделочная доска из HPL» в «Аксессуарах» — HPL, не ротанг); иначе по разделу с суффиксом/привязкой (табл. ниже), иначе по названию (`роуп` → Роуп, `ротанг` → Ротанг, `HPL` → HPL, `шпон` → Шпон), иначе `None`. `Material`/`Category` — `get_or_create` по slug (как `seed_demo`).
- **Категория**: по разделу (табл.), иначе по названию: «Комплект» → komplekty; «Кокон» → podvesnye-kresla; «Кресло», «Стул», «Пуф» → kresla; «Диван» → divany; «Шезлонг» → shezlongi; «Стол» → «Кофейный»/«Лаунж» → stoly-kofeynye, иначе stoly-obedennye; «Кашпо», «Чехол», «доска» → aksessuary; «Комод», «Сундук», «Этажерка» → без категории.
